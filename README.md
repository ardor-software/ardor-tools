## Why Ardor Wallet

The wallet is a Java desktop application, so it runs on the three platforms most people already own and needs no browser extension. It opens the parent chain and the child chains from a single secret, which is why one written phrase can recover the whole portfolio rather than only its largest balance.

Choose a full client and the chain is validated on your machine, which forging needs. Choose the light client and the wallet starts in seconds, reading balances from remote nodes until they catch up. Both modes reach the same exchanges, the same asset tools and the same data cloud.

- One recovery phrase for ARDR and every child chain the wallet opens.
- Full or light client, switchable after installation.
- Assets with royalties, dividends to every holder, and on-chain polls.
- Ledger and Trezor support for people who want a signature on a device.

The download buttons above install the wallet; this repository is a separate utility kept in the same account.
